# مجلد Unsloth — أُعيد بناؤه من الصفر

حُذف كل ما كان هنا في ٢٦ أكتوبر، وبُني على دروس المحاولة الأولى. لا شيء في هذا
المجلد يؤثر على الموقع أو النشر؛ هو معمل مستقل.

```
unsloth/
├── README.md          ← هذا الملف
├── build-tasks.mjs    ← يبني المهام من research/
├── run-local.mjs      ← يشغّل كل المهام على نموذج محلي تلقائياً
├── grade-answers.mjs  ← يفحص الإجابات ويجمعها
├── answers/           ← تُنشأ تلقائياً (غير محفوظة في git)
└── tasks/             ← 705 ملفاً، ٥ أسطر في كل ملف
```

## ١. لماذا فشلت المحاولة الأولى — ثلاثة أسباب

| السبب | الدليل من المخرجات المحفوظة |
|---|---|
| **عشرون سطراً في المهمة** | `w49out` و`w50out` و`w51out` انقطعت في منتصف سطر: `عبدالله بن أ…` |
| **طلب إعادة المدخل** | النموذج أعاد الأعمدة الثلاثة بلا إجابة، لأن النسخ استهلك حدّ الإخراج |
| **التعليمات في رسالة نظام منفصلة** | النموذج الصغير يتبع المثال الذي في الرسالة نفسها أكثر بكثير |

وليس من الأسباب: الترميز. تحققتُ من البايتات — الملفات UTF-8 سليمة.

| | قبل | بعد |
|---|---|---|

## ٣. الطريق الأول — تشغيل تلقائي (المفضّل)

شغّل النموذج على خادم متوافق مع OpenAI (Ollama، llama.cpp server، vLLM، LM Studio):

```
set UNSULOTH_URL=http://127.0.0.1:11434/v1/chat/completions
set UNSULOTH_MODEL=qwen2.5:7b-instruct

node unsloth/run-local.mjs --limit 3      ← جرّب ثلاثة أولاً
node unsloth/run-local.mjs                ← ثم الكل
node unsloth/grade-answers.mjs --all
```

`run-local.mjs` لا يعيد كتابة إجابة موجودة إلا مع `--force`، ويتخطى ما أُجيب.

## ٤. الطريق الثاني — لصق يدوي

إن كان النموذج داخل دفتر Unsloth فقط:

1. افتح `tasks/people-001.txt` وألصقه كما هو.
2. احفظ الرد في `answers/people-001.txt`.
3. `node unsloth/grade-answers.mjs tasks/people-001.txt answers/people-001.txt`

## ٥. شكل الخرج

المدخل:

```
عبدالله بن الزبير	Abdullah Bin Al Zubair Street	الشارقة
```

الخرج — سطر واحد فقط:

```
صحابي، ابن الزبير بن العوام وأسماء بنت أبي بكر	https://ar.wikipedia.org/wiki/عبد_الله_بن_الزبير
```

**السطر الفارغ إجابة صحيحة** تعني «لا أعرف»، والفحص يحفظه ولا يحذفه.

### ما يرفضه الفحص

| مرفوض | لماذا |
|---|---|
| إعادة المدخل | تُكتشف آلياً |
| إجابة بلا رابط | لا تُقبل |
| إجابة بالإنجليزية | البطاقة عربية |
| عدد أسطر مختلف | خلل في المحاذاة |

## ٧. الحصيلة المتوقّعة — بصراحة

- **`words-*`** (٥٧١ مهمة، ٢٨٥١ كلمة): أغلبها أسماء مواضع محلية لا ترد في أي قاموس
  رقمي. المتوقّع أن يعود معظمها فارغاً. هذا ليس فشلاً.
- **`people-*`** (١٣٤ مهمة، ٦٦٩ اسماً): أنفع. كثير منها صحابة وعلماء لهم تراجم
  منشورة.

لن يُدمج شيء آلياً في الموقع. كل سطر يمرّ على `tools/editorial-lint.mjs`
و`tools/arabic-lint.mjs`، ويقارن بما لدينا، ثم يُدمج يدوياً.
