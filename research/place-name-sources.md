# مصادر معاني أسماء المواقع الإماراتية

مصادر عربية على الشبكة تشرح معاني أسماء المناطق والشوارع، استُخدمت لتوسيع قاموس المعاني.

## ١. محاضر ليوا — الإمارات اليوم (٢٥ يوليو ٢٠١٠)
https://www.emaratalyoum.com/life/culture/2010-07-25-1.270305

شهادة عيد بن أحمد المنصوري، من أهل ليوا، يشرح فيها سبب تسمية كل محضر. أنفع مصدر وُجد حتى الآن
لأنه يغطي أسماء الظفرة التي لا توجد في أي معجم رقمي. اقتباسات حرفية:

| الاسم | المعنى كما ورد |
|---|---|
| الخريمة | «المنطقة مفتوحة وأرضها سهل» |
| العد | «ماء عذب قوي التدفق في أرض حصوية» |
| المارية | «مرتفعة تظهر للعيان، علامة مميزة» |
| خنور | «مدخلها ضيق» |
| الطرق | «يبدو كرأس جبل يرتفع في المنتصف» |
| ردوم | «كثبان رملية صغيرة على هيئة جبال» |
| بوصدين | «صاد على صوب واحد» |
| كية | «أرض شديدة الخصوبة» |
| موقب | «بئر ماء وقب أي صغير» |
| قطوف | «تقع على مسن الوادي» |
| القرمدة | «فوق رمال مقرمدة» |
| نميل | «في أرضها نمل كثير» |
| النشاش | «كان صعب المظهار» |
| الييف | «أرض صادة لها وجه واحد يسهل الوصول منه» |
| سريط | «الرمل يتحرك ويدفن النخيل كأنه يسرطه» |
| صبخة | «كانت أرضا سبخة» |
| ثروانية | «كثيرة الارتفاع» |
| الجبانة | «أرض منجرة عن الطريق» |
| حميم | «ماء خور، نسبة لحرارة الماء» |
| عرادة | «الشجر الموجود فيها من نوع العراد» |

أُضيفت ٢٤ لفظة إلى القاموس، وتغطي ٦١ شارعاً.

## ٢. أسماء مناطق دبي — البيان (١٣ أبريل ٢٠٢٥)
https://www.albayan.ae/lifestyle/culture/history/39159

مقابلات مع الباحث فهد علي المعمري وجمعة بن ثالث:

- **القوز**: «التلال الرملية المستديرة»، وتسمى أيضاً أقواز وقيزان.
- **المرقبات**: آبار بُنيت لها «رقاب» لتحميها من الانهيار.
- **القصيص**: من «اقتصاص الأثر» — تتبع أثر الإنسان والحيوان في الرمال.
- **بر دبي / بر ديرة**: «البر» اليابسة مقابل البحر.
- **يابية**: أحواض صغيرة لسقي الحيوانات.
