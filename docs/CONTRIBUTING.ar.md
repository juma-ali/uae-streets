# المساهمة في شوارع الإمارات

ملخّص بالعربية. المرجع الكامل — الأدق والأحدث — هو
[CONTRIBUTING.md](../CONTRIBUTING.md) بالإنجليزية.

## قاعدة المحتوى

كل مدخل يجب أن يقول كيف عُرف اسمه:

- **موثّق** — سُمّي على اسم شخص أو حدث أو معلم مسجّل.
- **رواية محلية** — تفسير شائع على الألسن بلا سجل رسمي. يُصنَّف كذلك،
  ولا يُقدَّم أبداً على أنه حقيقة.

عند الشك، اختر «رواية محلية». هذا هو الخيار الأمين.

## أضف شارعاً

1. افتح `data/streets.js`.
2. انسخ أي مدخلاً موجوداً، من `{` إلى `},`.
3. ألصقه قبل القوس الأخير `]`، ثم غيّر القيم.
4. تأكد أن `id` فريد (بأحرف لاتينية صغيرة وشرطات، بلا مسافات).
5. احفظ وحدّث الصفحة — تتحدّث العدادات والمرشّحات والبحث تلقائياً.

## الحقول

| الحقل | إلزامي | ملاحظات |
|---|---|---|
| `id` | نعم | فريد، ويصبح رابط المشاركة `#street=...` |
| `emirate` | نعم | `abu-dhabi` · `dubai` · `sharjah` · `ajman` · `uaq` · `ras-al-khaimah` · `fujairah` |
| `category` | نعم | `person` · `place` · `word` · `tribe` · `event` |
| `origin` | نعم | `documented` أو `local` |
| `ar` | نعم | كما هو مكتوب على اللوحة |
| `en` | نعم | الصيغة الإنجليزية الشائعة |
| `translit` | لا | النقل الصوتي، مثل `Shāriʿ al-Waṣl` |
| `meaning` | نعم | سطر واحد، بالعربية والإنجليزية |
| `story` | نعم | جملتان إلى ثلاث، بالعربية والإنجليزية |
| `refs` | لا | المصادر، تظهر في نهاية لوحة التفاصيل |

## المصدر شرط

لا يُنظر في تصحيح أو اقتراح دون **مصدر عام يمكن التحقق منه**: كتاب أو بحث
أكاديمي، أرشيف صحفي، إصدار بلدي أو وزاري، خريطة رسمية. منشورات شبكات
التواصل والمدونات بلا مصادر والذاكرة الشخصية ليست مصادر.

إن كانت الرواية شفهية فعلاً، فاذكر ذلك وسمِّ من رواها وأين — يمكن تسجيلها
كرواية محلية.

## قبل الإرسال

```bash
node tools/arabic-lint.mjs      # فحص آلي للنص العربي
node tools/arabic-review.mjs    # المداخل التي تغيّر نصها العربي
git add -A && git commit -m "..." && git push
```

معايير الكتابة العربية في [arabic-style.md](arabic-style.md).
والأعمال المفتوحة في [ROADMAP.md](ROADMAP.md).
